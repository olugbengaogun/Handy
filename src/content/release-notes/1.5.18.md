## What's new in 1.5.18

This update brings the latest improvements from the upstream Handy project into Handy Plus.

- **More resilient transcription.** Whisper and other GGUF models now run in their own background process. If a model crashes or freezes, Handy Plus keeps running and recovers on the next dictation instead of going down with it.
- **Cancel stops transcription too.** With Whisper and other GGUF models, pressing cancel while a recording is being transcribed now stops the transcription right away, instead of letting it finish in the background.
- **Clearer loading status.** When a model takes a while to load, Handy Plus now says it is loading, in both the overlay and the Live preview, instead of showing a stuck "Transcribing...".
