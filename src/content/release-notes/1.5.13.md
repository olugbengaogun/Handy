## What's new in 1.5.13

**Caps Lock, Page Up, Page Down, Print Screen, Scroll Lock and Num Lock now work as shortcuts.** These keys were recorded under names the shortcut system could not read back, so binding one appeared to succeed and then silently did nothing. If you tried one of these before and gave up, set it again — it will hold now.

**Copying from History tells you the truth.** The copy button showed "Copied" whether or not the text actually reached your clipboard. It now confirms only on success, and reports an error when the clipboard is unavailable.

Also includes the latest upstream fixes, plus a documented workaround for an empty recording overlay on Hyprland and Omarchy.
