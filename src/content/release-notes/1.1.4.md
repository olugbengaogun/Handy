## What's new in 1.1.4

A privacy correction and a small tool for measuring accuracy.

- **Recordings are no longer kept by default on a new install.** Keeping the
  audio of everything you dictate should be something you chose, not something
  you inherited. If you have already set this either way, your choice is left
  exactly as it is — this only changes what a fresh install starts with.
- **A failed transcription no longer holds on to its audio.** Until now, if
  transcription failed, the recording was kept regardless of your setting, so
  that you could retry it. That quietly turned "don't keep my recordings" into
  "unless something goes wrong". With keeping switched off, the recording is now
  deleted as soon as the attempt is filed — and that entry cannot be retried,
  which Handy Plus tells you if you try.
- **You can now test whether naming your language helps.** Transcribing a file
  from the command line accepts a language for that one run, without touching
  your saved settings. If letting Handy Plus guess the language has ever
  garbled the start of a recording, this makes it possible to measure whether
  saying so outright works better for your voice.

Transcription itself is unchanged in this release, including its speed.
