## What's new in 1.1.2

This is a maintenance update, bringing the latest fixes from the upstream
Handy project into Handy Plus.

Areas improved in this release:

- Audio recording — starting and stopping a recording is smoother, because
  the work that prepares the microphone no longer blocks the app while it
  runs.
- The recording overlay — it no longer keeps animating while hidden, which
  saves a little battery.
- Post-processing — clearer messages when a post-processing request fails.
