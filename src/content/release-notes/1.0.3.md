## What's new in 1.0.3

### Accent-coloured text is actually readable

"Update available" in the footer was painted in the pale logo blue, which
measures 1.39:1 against the light background — effectively invisible, on the
one label whose whole job is to be noticed. The same colour was used as text
in ten other places: the model dropdown's active row, the language and model
pickers, History's filter buttons, links inside What's New, and several hover
states.

All of them now use a darker version of the same blue that clears the
accessibility standard with room to spare. The logo, sidebar highlight and
other coloured backgrounds are unchanged — pale is right behind something,
just not as something. Dark mode looked fine already and is untouched.

### Behind the scenes

Automatic updates from the original Handy project now survive CJ publishing
his own releases, which previously collided with this fork's version numbers
and would have quietly stopped the automation.
