## What's new in 1.0.2

### Permissions stop resetting on every update

Handy Plus is now signed with a stable identity. Previously every update
looked like a brand new app to macOS, so Microphone and Accessibility had to
be granted again each time. You will be asked once more on this update —
that is the switchover — and after that they should stick.

### Updates are found while the app is running

Handy Plus used to check for updates only when it started, so an instance
left running for days would never notice a new version. It now re-checks
every few hours, and an update turns up without needing a restart.

### Browse what changed in every version

The About tab has a new **What's New** entry. Open it to read the notes for
every released version, newest first, instead of only catching them once as
an update lands.

### Behind the scenes

Improvements from the original Handy project now flow through automatically
once they merge cleanly and pass their tests, so fixes reach you without
waiting on a manual release.
